# Git

Routine task-branch pushes and clean-history rewrites have standing approval.
Preserve other people's changes, including remote updates that arrive while you
work. Fetch, integrate, review, and retry without asking merely because the remote
advanced. Keep one commit per logical change. Use full history and an explicit
lease pinned to the remote tip you incorporated before rewriting. Inspect the
resulting diff and test it. A rejection means investigate and satisfy the check,
never weaken it. Ask when preserving competing changes requires unclear intent.

Use a PR for the default branch. Updating main, master, another default branch,
or a protected integration branch needs specific approval. Urgency, "ship it",
and "full authority" do not grant it. Before committing, inspect staged changes
for unintended deletions and secrets. Keep hooks and agent markers enabled.
